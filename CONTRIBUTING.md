# Bidra

Takk for at du les kartet kritisk.

- **Fagfeil og forslag:** opprett eit [Issue](https://github.com/lektorodd/fagkart/issues). Skriv kva node (namnet i kartet, eller ID-en) det gjeld, kva du meiner er feil, og helst kva som bør stå i staden.
- **Pull requests:** blir lesne. Dette repoet er ein eittvegs-kopi frå eit utviklingsrepo, så ein PR blir ikkje fletta direkte; innhaldet blir retta der og kjem med neste utgåve (éin commit per utgåve).
- **Aldri elevdata:** ikkje legg namn, vurderingar eller andre opplysningar om elevar i Issues, PR-ar eller filer, heller ikkje i eksempel.
- **Læreplantekst:** kompetansemåla står ordrett som i læreplanen (`kjelder/`). Dei blir ikkje omskrivne.
- **Språk:** innhald og tekst i sida er nynorsk. Kode og kommentarar i koden er på engelsk.

Før du føreslår ein kodeendring: køyr `python3 scripts/lint.py` og testane (sjå README).
